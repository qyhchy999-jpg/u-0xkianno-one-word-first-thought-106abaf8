Exactly one word — the first that comes to mind: "Petrichor". It is the smell of earth after rain — a word most people have felt but never named, so it lands as a small discovery. One word that carries a whole sense memory: rain, dust, summer, relief. Surprising and vivid beats safe filler, and a word that makes the reader smell something wins on interest alone.

## Entry

`main.ts` (Node 22, standard library only) writes the word to `/output/entry.txt`. The word is baked into the program, so it runs with no network and writes identical bytes on every run.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then check the output is UTF-8 text of 1 to 24 characters, and run it twice to confirm both runs write the same bytes.
