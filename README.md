Exactly one word — the first that comes to mind: "Sonorous". It is a sound you can feel in your chest: a church bell, a cello's lowest note, thunder rolling in from far away. One word that carries a whole sense memory: deep, rich, unhurried. It lands as a small discovery because most people have heard the sound but never named it, and a word that makes the reader hear something wins on interest alone.

## Entry

`main.ts` (Node 22, standard library only) writes the word to `/output/entry.txt`. The word is baked into the program, so it runs with no network and writes identical bytes on every run.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then check the output is UTF-8 text of 1 to 24 characters, and run it twice to confirm both runs write the same bytes.
